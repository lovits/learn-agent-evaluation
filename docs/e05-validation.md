# 第5课验收记录

复用第4课真实Agent的原始产物和当次检索快照，未新增Agent运行。五种受控回答、证据改版和真实记录七条样本实际调用DeepEval FaithfulnessMetric与Ragas collections Faithfulness，共34次模型请求，0个指标运行错误。

初次入口未启动产生14项连接错误、0次实际模型调用；错误记录单列，不当有效零分。逐声明truths/claims/verdict/NLI和原始prompt响应均保留。模型实际拆分与教学预设不同也照实呈现。

同ID内容哈希改变后拒用旧标注。DeepEval默认及penalize开关对同组verdict重聚合，未额外请求模型。NaN与异常分开保存。另对真实回答的来源ID封装做独立补测，报告与七条主实验分开。

本课不评价最终业务正确性、完整性、切题性或总体任务成功，也不声称小型开发实验证明了泛化能力。代码检查通过，本地59项测试通过。Docker断网环境59项测试同样通过。
