# e11 参考解释

[练习](exercises.md) · [教材](README.zh.md)

1. 写入的 path 错而 content 对，两个键有一个匹配，非精确参数权重为 1/2；它不是执行成功的百分比。查看实际目标路径与产物，不能只读匹配分。
2. 有序 LCS 可以跳过额外项，只要求匹配部分保持次序；完全匹配还要求长度与每个位置的指定字段一致。重复调用需要看未去重的事件序列。
3. 看 result.status 和 output，目录不能作为目标文本文件写入。即使输出也匹配，还要确认参考覆盖了真实用户目标、保护条件及允许的替代路线。
4. 若只验指定文件工具流程，低分符合定义；若验允许方式下的复制目标，应覆盖合法路线或采用结果条件，不能为了参考方便偷偷禁止原本允许的 Bash。
5. 不能。还要看实际轨迹是否出现越界绕过；拒绝是正确的政策结果，不应一律计为工具崩溃。本课文件工具的路径保护也不能代表 Bash 已被同样隔离。
6. 集合会去掉名称与参数完全相同的重复项。重复次数、成本与顺序需保留每个事件及其唯一编号，或使用符合任务的序列条件。
7. 没有参数可判，空值约定不证明必要动作完成。本课将语义参数分标为不适用，参考覆盖与产物观察仍能发现没有执行复制。
