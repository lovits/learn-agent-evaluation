# 课程的讲解方式

先让读者遇到一个具体问题，再引入解决它的最小机制。跟随 Learn Claude Code 实际课文的节奏，章节名称和步骤数量由问题决定。

正文要能沿着数据走：任务从哪里进入，模型看见什么，关键函数改变什么，评分器根据什么得出结论。完整实现放在源码文件中，课文只保留理解当前机制需要的片段。

每课一个核心知识点，相关概念围绕它展开。知识库部分使用 Datawhale TinyRAG，编程 Agent 保持 Learn Claude Code 的递进路线。评分课可以复用已有 Agent，不必为每个指标再增加 Agent 功能。

## 教材与源码导读

教材从具体困难开始，用短代码解释思路和工作原理，再给小例子及“试一下”。章节可以按机制命名，不规定固定六节，也不规定每节必须分六步。

源码导读追到实际函数、输入字段、结构化裁决与聚合公式，说明 DeepEval、Ragas 同名方法的差异、方向、分母和空值边界。链接指向固定提交。

示例数字只用于解释计算，标明手算或构造性质。正文不放制作历史、验收计数、实测成绩列表或阅读服务启动教程。代码任务中的行为检查属于评测方法，应当解释其依据。

## 语言与图

先解释为什么需要某个机制，再读最关键的代码。用具体变量和输入输出衔接段落，不堆术语或反复小结。图只在结构或数据流难以靠短文说清时使用。

## 源码与运行

各课只接已介绍的共享模块，完整集成放在结课项目。Docker 与知识库挂载由项目配置负责，AI 可按配置准备运行环境。

已有原始记录继续作为研究材料保存，不进入课程的主阅读路线。文档改写不产生新的运行成绩。
