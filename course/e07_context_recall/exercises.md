# e07 练习

[教材](README.zh.md) · [覆盖与评分代码](eval.py) · [参考解释](solutions.md)

1. 设想只保留 `atlas/logs.md`、移除 `atlas/release.md`，沿用本课的三条参考事实。请列出遗漏的事实，并分别算出文档召回、事实召回与文档精度。
2. 保持 `missing_logs` 的上下文不变，分别使用完整三条事实与删掉 `log_days` 后的两条事实运行召回计算。得分升高时，怎样从记录里区分这是检索能力改进还是参考清单缩水？
3. 一份长文档的前半段写审计日志期限，后半段写发布命令。如果检索只返回了前半段，按文档路径查表的 `summarize` 会怎样误判？把来源映射改到什么粒度才可靠？
4. 查看 `ContextualRecallMetric` 返回的原始 `verdicts` 列表。为什么不能直接把 `verdict.expected_output` 当作当前这一条裁决对应的事实文本，也不能机械按下标对齐自定义事实 ID？
5. 区分以下四种情形：没有参考事实；有参考事实但上下文一条都没覆盖；裁判返回空 `verdicts` 列表；参考有三条句子却只收到两条裁决。哪些属于有效零分，哪些需要标记错误或人工复核？
