# e15 练习

[教材](README.zh.md) · [参考解释](solutions.md)

1. `baseline` 与 `candidate` 各自产出了 6 条结果。能不能直接把两个列表按位置相减来计算差值？请构造一个按位置相减会算错的反例。
2. 如果把同一道题重复运行 20 次，能不能把总样本量当成 20 道独立题目？先合并同题重复再按题族重采样解决了什么问题，目前数据还缺少什么？
3. 两个跨文档题各自提升了 `0.5`，当前版本题却下降了 `1`。按题族等权计算整体差值是多少？看到这个总均值后，是否能直接接受改动，还需要核对哪些信息？
4. 某次运行中，`candidate` 的一条样本裁判接口报错（`status != "ok"`）。这一条应该记成 `0` 分、把两侧整题删除，还是保留失败记录并减少有效配对数？
5. 某次调用的 `usage` 报告 `input_tokens=1000`、`cached_input_tokens=800`、`output_tokens=100`。能不能把总 token 算成 `1900`？在没有提供方单价表时，能否把美元费用记为 `0`？
