# 第3课参考答案

1. 交集2，precision=1，recall=0.5，F1=2/3。集合去重，所以重复不改变分数。若关心重复或顺序，继续用轨迹合同或另写序列指标。
2. 中文回答可能语义正确，但不是目标JSON字符串。三种分数衡量不同维度，不能相互替代。
3. 正确文字不证明文件已落盘。独立验收器读取真实文件、输出和退出码产生状态；模型自报不能当状态证据。本课受控夹具模拟这个状态差异。
4. 评分标准改变后，paraphrase应在格式维度失败；这属于标准版本改变，不能与旧实验直接合并通过率。
5. 非法输出是裁判运行失败，应单列失败数量。0表示裁判成功运行后判断不满足标准。
6. 分支到分数的映射固定，但同一节点的判断可能变化。先让标注者独立标注、讨论分歧并形成rubric，再在校准集选择阈值，最后冻结配置运行留出集。四条教学样本不足以估计可靠性。
