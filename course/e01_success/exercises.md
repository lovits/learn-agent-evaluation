# e01 练习

1. 打开 [code.py](code.py)，顺着一次 Bash 调用找一找：命令的 `exit_code` 和 `stdout` 在哪一行写入评测记录，又在哪一行重新送回给模型？
2. 假设一个模型第一轮就不调用任何工具，直接回复 `"已完成"`。此时 `agent_loop` 会以什么状态退出？[eval.py](eval.py) 为什么依然会判为未通过？
3. 在一次成功运行之后，先保留原来的运行记录不变、只把磁盘上的 `hello.py` 改成错误内容，观察评分变化；再把文件改回正确逻辑，换成单引号并加一行注释，看看评分结果又会怎样。
4. 如果把任务改成“运行一段损坏的脚本，并告诉我它报了什么错”，还能直接用 `exit_code == 0` 作为任务成功的条件吗？应该怎样区分“工具命令返回非零退出码”和“Agent 任务执行失败”？
