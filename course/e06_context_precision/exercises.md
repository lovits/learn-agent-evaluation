# e06 练习

[教材](README.zh.md) · [排序与原生评分](eval.py) · [参考解释](solutions.md)

1. 固定标签列表 `[0,1,0]`，分别把其中的 `1` 移到首位和末位。为什么三种顺序的普通精度完全相同，而列表 AP 却不同？请逐位置写出相关的 `P@i`。
2. 在 `[1,0,0]` 末尾再追加一个 `0` 变成 `[1,0,0,0]`。普通精度和 `list_ap` 各怎样变化？这说明 `list_ap` 对哪类噪声不敏感？
3. 计算序列 `[1,0,1]` 的 `rr` 和 `list_ap`。为什么 `rr` 看不出第二个相关项的位置差异？多条查询怎样才能形成 MRR？
4. 假设某段检索资料里包含 `1` 条直接回答问题的陈述和 `3` 条无关背景陈述。为什么 `ContextualPrecisionMetric` 与 `ContextualRelevancyMetric` 对同一份材料会给出不同分数？
5. 如果检索器只返回 `1` 条有用片段，列表 AP 就能拿到 `1.0`。为什么这依然不足以说明知识库里的必要证据都已找齐？还缺哪一类检查？
6. 调用 `ContextualPrecisionMetric` 时传入了 `3` 段上下文文本，但模型裁判只返回 `2` 条裁决。为什么 `judge_precision` 要将其判为对齐错误，而不是把缺少的第三条自动记为 `no`？
