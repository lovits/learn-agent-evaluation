# e04 练习

[教材](README.zh.md) · [评分代码](eval.py) · [参考解释](solutions.md)

1. 保持三个 JSON 字段的名称和类型都正确，只把 `explanation` 的值改成 `"接口位于 upload.md"`。`UploadContract` 和 `explanation_metric` 分别会给出什么结果？为什么规则指标不应该代替语义指标去解释文字含义？
2. 把 `explanation` 改写成意思完全等价的英文句子。用简单的字符串相等比较会怎样？按本课的 `GEval` 量表和步骤应该怎样判分？
3. 假设一段回答只写了“发送前先检查文件大小”，漏掉了超限返回 `HTTP 413`。请沿着 `Rubric` 分档、分数归一化与 `threshold` 比较这三个步骤，说明最终得分和通过状态是如何算出来的。
4. 给定预测集合 `{"header", "extra"}` 与参考集合 `{"header", "limit", "status"}`，手算 `precision`、`recall` 和 `F1`。如果分别将预测集或参考集清空，哪些分母会变成空值？
5. 如果人为让 `JudgeModel` 在请求时抛出 `OSError`，为什么这个结果不能当成 `0` 分计入平均分？汇总整批样本的评分报告时，除了有效平均分，还应该展示哪些统计量？
6. 假设业务规定 JSON 格式合约与解释语义两项必须同时达标，而且两项的 `threshold` 都设为 `1.0`。如果直接把两个分数相加除以 2 作为总分，会掩盖什么问题？
