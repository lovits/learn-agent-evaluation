# 课程说明

目标是能独立设计 Agent 评测样本，选择和解释指标，定位失败，并用相同数据比较版本。学习过程围绕一个编程 Agent，知识库使用 Datawhale TinyRAG，方法与关键源码依据来自 DeepEval、Ragas。

## 学习路线

[16课大纲](curriculum.md)列出每课核心问题、知识点和教材入口。基础顺序为：最小循环、样本、评分标准，接着进入 RAG 链路，再建立数据与比较方法，最后评价复杂 Agent 行为并形成回归。

## 每课内容

教材通过一个具体问题解释核心机制。源码导读继续追到实际实现及两框架的判分依据。可运行代码只引入该课需要的增量，动手问题与参考解另放。

| 文件 | 用途 |
|---|---|
| README.zh.md | 具体问题、机制与关键代码 |
| source_walkthrough.md | 完整调用链、公式、框架差异与来源 |
| code.py | 本课场景或确定性计算 |
| eval.py | 评分入口 |
| cases.jsonl | 任务或明确标记的构造样本 |
| exercises.md / solutions.md | 动手题与参考解释 |

评分课可直接复用前课 Agent，完整运行时在综合项目接入。知识库只读，工作区可写，模型登录留在宿主，业务评分与被测执行分开。

## 写法

先遇到困难，再增加机制，再沿代码解释它怎样工作。章节按知识点命名，保留必要算例与“试一下”，不强制固定小节数量。图用于解释关键结构。

正文聚焦知识与原理，制作历史、部署步骤、运行成绩与验收统计不占据学习路线。具体文字要求见[写作方式](teaching-method.md)。

## 依据

[版本](../references/versions.json)固定 Learn Claude Code、TinyRAG、DeepEval 和 Ragas。每课源码导读链接实际使用的函数和官方文档；模型裁决与程序事实分别解释，示例数字不冒充真实成绩。
