# e06 参考解释

1. 三种顺序都只有一条相关项，普通精度均为 1/3。相关位置的 P@i 分别为 1/2、1、1/3；列表内相关数为 1，所以 AP 分别相同于这三个值。
2. 普通精度从 1/3 降为 1/4；AP 仍为 1。新增尾部噪声没有改变任何相关位置的 P@i。高 AP 不能证明列表干净。
3. RR 为 1，AP 为 `(1 + 2/3) / 2 = 5/6`。RR 只看第一个相关项，AP 还使用列表内后续相关位置。MRR 是多个查询 RR 的平均，不是把一个问题的值换个名字。
4. 片段级标准可以只要求它对参考答案有帮助；陈述级标准会把其中三条无关信息也纳入分母。评分单位和相关性判据都需要明确，不能只看指标名称比较数值。
5. 不能。分母只含当前列表中被判相关的项，尚未找到的必要事实不在这里。下一课用参考事实的覆盖与召回讨论遗漏。
6. 没有收到判定不等于判为无关。保留原始响应和错误状态，分数为空，检查裁判输出。数量对齐只是一项检查，数量正确也不保证每个判定语义正确。
