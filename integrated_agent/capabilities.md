# 综合 Agent 的机制地图

编号沿用固定 Learn Claude Code 的 s01–s17。课程先逐课解释必要增量，再在综合运行时接起来。每个机制都对应一个能观察的问题。

| 机制 | 在运行时做什么 | 评测关注什么 |
|---|---|---|
| s01 循环 | 模型请求、执行工具、回填结果 | 实际动作、停止与任务完成 |
| s02 工具 | 声明参数、按名字分发 | 选择、参数、顺序与执行结果 |
| s03 权限 | 执行前允许、拒绝或批准 | 被拒绝动作有没有真的发生 |
| s04 hooks | 在输入、工具前后与停止处接入处理 | 事件覆盖、拒绝顺序与状态 |
| s05 清单 | 保存显式计划与进度 | 计划内容与实际执行是否对应 |
| s06 子 Agent | 用新消息处理局部任务 | 交接完整性与局部、整体结果 |
| s07 技能 | 先给目录，再按需加载正文 | 实际加载的版本与使用范围 |
| s08 压缩 | 转存、裁剪与摘要历史 | 当前要求、工具配对与证据是否保留 |
| s09 记忆 | 持久记录与新会话召回 | 临时事实、过期信息与约束冲突 |
| s10 任务系统 | 依赖、owner 与状态持久化 | 合法认领、依赖顺序与并发更新 |
| s11 后台 | 先返回 ID，稍后给真实输出 | 占位、终态、通知与清理 |
| s12 调度 | 到期、持久交付与确认 | 收到提示以后是否实际做完 |
| s13 团队 | 持久角色、邮箱、审批与 worktree | 任务归属、当前批准与文件交接 |
| s14 MCP | 动态发现外部工具并绑定 | 可见工具、授权与实际参数 |
| s15 集成 | 共用循环连接上述机制 | 状态能否一起闭合、证据能否追踪 |
| s16 工作流 | 可信步骤、并行与 journal | 恢复输入、成功缓存与结论依据 |
| s17 目标循环 | 停止时判断继续或返回 | 目标证据、上限、异常与未完成状态 |

知识工具使用 TinyRAG；它负责片段检索，DeepEval 和 Ragas 负责相应质量评价。检索相似度、语义裁判分与实际业务完成状态分别解释。

## 读取时留意这些差别

逐课的严格教学接口与原生集成接口不完全相同。例如第13课清单只允许一个进行中项目，原生 TodoWrite 接受更多输入形式；阅读时按当前入口的合同理解。

原生工作流的 `SimpleJsonSchema` 只支持有限子集；调度加载器对损坏文件的处理也有限。目标控制可恢复部分事件状态，当前 CLI 没有跨进程恢复整个会话。

MCP 沿用进程内模拟服务，docs 读取真实知识库；工作区、进程组与角色工具守卫各有作用，不等同于任意代码的通用隔离。
