# e15 参考解释

[练习](exercises.md) · [教材](README.zh.md)

1. 不能。必须按 `(case_id, repeat, version)` 配对相减。反例：异步并发评分时，`baseline` 按 `[题1, 题2, 题3]` 顺序返回，而 `candidate` 中 `题2` 接口超时缺行、先返回了 `[题3, 题1]`；按位置相减会把 `题1` 的 `baseline` 和 `题3` 的 `candidate` 错配在一起。
2. 不能。同题重复主要反映同一任务在采样或执行秩序下的波动，每次运行共享相同的题干、参考答案和底层文档。先按 `case_id` 合并重复再对题族做重采样，可以避免把同题重复虚增成独立样本并保留题族内部相关性；但若要支持更可靠的统计推断，仍需要更多独立题族、清晰的抽样代表性与留出测试集。
3. 三个题族等权平均时，`(0.5 + 0.5 - 1) / 3 = 0`。无论总均值是 `0` 还是略大于 `0`，都不能仅凭均分接受改动，还需要逐一核查 `regressions` 里的退化原因、关键题型是否出现回退、配对覆盖率是否完整，以及新增上下文带来的 token 与延迟开销。
4. 应保留原始错误日志和轨迹，将该行 `quality` 设为 `None`，并在 `compare` 里把它划入 `missing_pairs`，同时明示 `valid_pairs` 与 `pair_coverage`。评分接口故障属于结果未知，既不能当成业务表现 `0` 分去惩罚模型，也不应该静默删掉记录让人误以为覆盖率为 100%。
5. 不能直接相加成 `1900`。多数模型接口的 `cached_input_tokens` 已经包含在 `input_tokens` 之内（具体口径以对应提供方文档为准），直接再加会把缓存部分重复计数。没有可靠价格表时，美元费用应保留为 `None`（未知），不能写成 `0` 美元误导成零成本，并且要把 Agent 开销与裁判开销分开记录。
