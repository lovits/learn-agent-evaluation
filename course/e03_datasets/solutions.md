# e03 参考解释

1. 程序按审核后的 `family + intent` 去重。换键会让重复题通过，因此标签本身也要审核；这段代码没有自动理解任意句子的语义。
2. 两题都属于 `upload-size`，两侧题族相交，`families_disjoint` 为假。按行随机拆分不能保证题族隔离。
3. 不够。哈希只能说明来源版本，无法证明旧参考仍正确。需要重新核对任务、引文、参考和边界，再记录审核。
4. 生成器统一设置 `pending`。参考可能误读原文，题意可能重复，类别也可能标错；要核对这些内容再批准。
5. 本课缺证据题限定“根据所给 upload.md”。在这个范围内，账单货币没有说明，合理参考是明确承认资料不足。它有清楚的目标和判据；一个未限定范围、无法核对答案的题则需要重写。
6. `Golden.expected_output` 来自审核后的参考，`LLMTestCase.actual_output` 来自真实运行，调用结果保存在 `tools_called`。本课尚未选定答案质量指标，所以不能把样本构造成功当作答案通过。
