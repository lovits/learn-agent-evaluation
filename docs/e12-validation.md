# 第12课验收

本课沿Learn Claude Code的具体问题、短代码和运行观察组织教材。正文保留六个部分、六个关键步骤；实际源码、练习、答案、实验和生成记录分别阅读。DeepEval/Ragas的字段校验、提示/schema、结构化判定、极性、聚合、异步差异与不适用范围保留在源码导读。

## 应用与独立验收

固定完整上下文、固定压缩路径以及当前区间记录增量路径分别在Docker实际执行。三条路径的各轮正常停止、版本行为、函数签名、原测试保护、记忆来源与最终目录一致性均通过独立核验。每个版本重新执行22个保留行为输入；这些公开教学样本是回归验证，不声称未见盲测。

后验model_inputs审查确认三条路径首个会话实际包含诊断日志全部42047字符。文本暴露不证明内部理解，字符阈值不等于token预算。新旧镜像、实验协议与历史失败保留，不以单条轨迹推断压缩性能优劣。

## 评分与覆盖

会话评分只看到用户请求和最终回答。真实文件检查、模拟器阶段覆盖与语义分数分别报告；原生SDK的默认空值分数和相反yes/no极性有边界测试。模型服务中断的评分记null，失败批次与恢复补跑分开，详细结果见[运行记录](../lessons/e12_conversation/run_summary.md)。

模拟器实际生成用户并调用真实Agent；受控一轮停止用于验证覆盖缺口。SDK异常保留已发生的交互与错误，不制造完整sample；实验是否正常结束也是场景验收条件。

## 实现范围

本课适配s08/s09所需子集：上下文转存、裁剪、摘要、分页恢复和跨会话记忆。完整主动压缩、超长重试、记忆整理回滚与其他17项机制仍在综合项目逐项核验。权限、文件/Bash工具与公开停止审查沿用已学代码。

可编辑图与PNG预览已核对；没有使用Desktop导出。知识库只读挂载、工作区和报告持久化、断网验收器独享条件文件，模型凭据留在宿主。构造协议fixture没有实际执行其中写出的工具请求；它只验证压缩与磁盘回读。

## 检查结果

本地与Docker断网均152项测试通过，自有代码Ruff通过。保留1条前课已有的DeepEval DAG接口弃用警告。测试覆盖工具配对、分页权限和非UTF8错误、摘要保留最新批次、失败请求不计送达、记忆范围与版本、原生样本往返、指标极性与空判断，以及正确文件不能掩盖step_limit。
