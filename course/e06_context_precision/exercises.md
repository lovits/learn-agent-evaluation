# e06 练习

[教材](README.zh.md) · [排序与原生评分](eval.py)

1. 固定标签 `[0,1,0]`，将有用项移到首位，再移到末位。为什么普通精度相同，列表 AP 不同？逐位置写出 P@i。
2. 在 `[1,0,0]` 后面追加一个 0。普通精度和 AP 各怎样变化？这说明 AP 对哪一种噪声不敏感？
3. 对 `[1,0,1]` 算 RR 和 AP。为什么 RR 无法反映第二个相关项的位置？多个查询怎样才形成 MRR？
4. 一段资料中有一条有用陈述和三条无关陈述。为什么“该片段有用”和“陈述相关比例”可能同时给出不同结果？
5. 只返回一条有用片段，列表 AP 可以为 1。能否据此声称知识库中所有必要证据都找到了？还缺哪类判断？
6. 裁判对三个字符串只返回两条判定。为什么这应是对齐错误，而不是第三条自动记为 no？
