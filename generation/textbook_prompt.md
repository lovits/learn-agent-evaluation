# 给 PocketFlow 的教材提示词

为会 Python、了解 Agent 与 RAG 的读者编写当前一课中文教材。课程通过编程 Agent 学评测：编程机制沿 Learn Claude Code 递进，知识库使用 Datawhale TinyRAG，判分方法与源码依据来自 DeepEval 和 Ragas。

以 curriculum.json 的当前课程条目为范围，参考 Learn Claude Code 实际课文的讲法：先给具体困难，引出最小机制，再沿真实关键代码解释工作原理，接一个算例或观察任务，最后自然引出下一课。

每课围绕一个核心知识点。标题根据问题命名，以问题、解决方案、工作原理、本课变化、试一下、接下来为主线。正文只放理解机制所需的代码，完整函数另行链接；不要提前导入整套集成 Agent。

源码导读解释框架输入、prompt/schema、裁决和聚合，保留方向、分母、空值及同名方法差异。来源链接使用材料中固定提交，区分程序事实、模型裁决和手算示例。

不在首页和教材放制作记录、改写进度、测试成绩、验收报告或教材服务启动教程。通过具体任务帮助读者理解 Agent 怎么设计、评测脚本怎么写，以及分数为什么这样算。

语言自然、直接，少术语堆砌，不用重复小结或格式化口号。图只解释必要结构。构造数字注明用途，不编造运行结果、人工审核、模型身份或费用。

硬约束：教程中不得出现任何安装、环境配置、启动服务或要求 AI 准备环境的内容。直接进入学习问题与代码。每课一个核心问题，只介绍当前代码中实际存在的机制。SDK 样本构造与指标评分分开解释。

全课程实际评测框架统一使用 DeepEval。Ragas 用于学习评测指标、数据集设计与关键源码，不为同一任务再写一套 Ragas 接入或重复评分。第一、二课统一使用普通流程图。图片不放大，只适度提高文字占比，节点写清动作、输入与输出。

主教材直接嵌入两张原生 SVG 矢量图，参照 Learn Claude Code 使用纯 SVG 文字和路径，源文件随仓库保存，GitHub 使用课程发布的图片地址。本地显示同一 SVG，飞书使用3倍像素 PNG，均保持正常显示尺寸；不增加交互图入口。图片位置和紧凑程度沿第一、二课，详细要求见 docs/course-requirements.md。
