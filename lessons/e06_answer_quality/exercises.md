# 第6课练习

1. 用户要认证头、限额、状态码，回答只有正确认证头。分别判断切题、事实precision与需求覆盖；给出你需要的输入字段。
2. 教学计数TP=1、FP=0、FN=2。手算precision、recall、F1与F2。解释为什么提高beta会更重视漏答。
3. 正向裁决[1,1,1]、反向[1,0]。对照固定Ragas源码，算其recall与直接反向覆盖率；指出它们何时可能不一致。
4. v1检索证据仍是1MiB，当前合成v2合同为2MiB。回答1MiB。分别选择Faithfulness与正确性的比较材料，再说明为什么旧记录不能随意改用新标准。
5. 证据没有重试次数时，比较“自动重试0次”“重试3次”“资料未说明，请补充配置”；给出拒答合同。若证据已经包含答案，同样的拒答如何评价？
6. 默认AnswerCorrectness的事实分0.5、相似度0.8、权重0.75/0.25，混合分是多少？为什么高语义相似度不能证明限额数字正确？标明哪些是人工演示。
7. 看一次实测的原始statements、TP/FP/FN和GEval reason，选出一处分歧。先检查reference、拆解粒度、版本与业务政策，再决定是否是裁判错误。若真实运行与你的预设不同，保留两者。
