# e07 练习

[教材](README.zh.md) · [参考解释](solutions.md)

1. 只保留 logs，移除 release。先列出遗漏的事实，再分别写出文档召回、事实召回和文档精度。不要把日志天数当成发布条件。
2. 固定 missing_logs 的上下文，对照完整参考与缺日志参考。分数上升时，怎样判断是检索改进还是参考改变？
3. 一份长文档前半段写日志期限，后半段写发布命令。如果只检索到前半段，按路径查表会怎样误判？把来源映射改到什么粒度才可靠？
4. 对照 DeepEval 的原始 verdicts 与本课事实 ID。为什么不能把每条 verdict.expected_output 当成当前事实文本？
5. 区分四种情况：没有参考事实；有参考但没有覆盖；裁判返回空列表；参考三条却只判了两条。哪些可以给有效零分，哪些需要拒绝或继续审核？
