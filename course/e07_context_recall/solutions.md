# e07 参考解释

[练习](exercises.md) · [教材](README.zh.md)

1. logs 支持日志天数，不支持命令和发布条件。文档召回 1/2，事实召回 1/3，文档精度 1。精度只看返回内容是否有用。
2. 保留候选内容、顺序、参考事实和来源版本供核对。上下文相同而参考从三条缩为两条，是分母和要求改变；不能称作检索改进。
3. 命中文档路径会把整份文档承载的事实都算成覆盖。应记录实际证据片段 ID、位置、版本与事实的关系，或对实际片段做语义判断；当前短文映射不能直接套到长文档。
4. 固定 DeepEval 实现把整段 expected_output 复制到每条 verdict，没有独立 statement 字段。需要结合原始理由回到参考核对；按列表顺序机械绑定自定义事实并不可靠。
5. 无参考时分母未定义，集合算式返回 None，语义入口拒绝。存在参考且全部不支持才是有效 0。空裁决在本课记错误；少判一句即使能算比例，也需要检查对齐，本课不会声称已自动解决这个问题。
