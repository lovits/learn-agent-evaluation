# 课程目标与制作规范

课程面向会写 Python、了解 RAG 与 Agent 的开发者，通过一个可运行的编程 Agent 串联数据准备、指标选择、评分排查、版本对比与持续回归。

## 范围

全课按[16 课大纲](curriculum.md)推进。第 1 至 4 课建立成功条件、样本、数据集与评分方法；第 5 至 10 课接入 TinyRAG，评测上下文与生成回答；第 11 至 13 课转向工具调用、交付产物与多轮会话；第 14 至 16 课完成裁判校准、版本配对比较与持续回归门禁。

每课只引入解释当前知识点所需的最小代码增量。工具分发、路径边界与记录结构先从小函数起步，后续指标课直接复用已有 Agent，结课项目将整条链路收拢到统一回归流程中。

## 课文与源码导读

主教材沿“问题 → 解决方案 → 工作原理 → 本课组件 → 试一下 → 接下来”组织，必要细节放在工作原理的子节中。正文只节选核心代码片段并说明数据如何流转，完整函数留在源码文件中；省略字段在正文或注释里交代清楚。

主教材正文专注讲解问题、机制、代码与判据，环境安装与运行细节放在项目配置中说明。各课的 `assessment.md` 与 `assessment.json` 单独记录样本来源、构造条件、实测数据、软件检查与误差分析，主教材末尾保留链接供读者按需查阅。

本仓库统一使用 DeepEval 作为评测框架，不再单设其他评测框架的对照章节。源码导读聚焦于本课调用链，以及 DeepEval、TinyRAG 和 Learn Claude Code 在官方文档与[固定版本](../references/versions.json)源码中的输入字段、判据、模型裁决、聚合公式与边界处理。

正文保持简洁具体的技术表达，按问题和变量流向衔接段落。两张流程图紧邻“解决方案”放置，沿用 Learn Claude Code 的原生 SVG 风格：纯 SVG 文本、浅色节点、菱形判断框与箭头连接，节点文字以 `16` 为参考、连线文字以 `14` 为参考，画幅保持紧凑。

## 目录约定

`course/` 下每课按需要提供 `README.zh.md`、`code.py`、`eval.py`、`cases.jsonl`、`source_walkthrough.md`、`exercises.md`、`solutions.md`、`assessment.md` 与 `assessment.json`。

`eval_course/` 存放模型调用桥接、TinyRAG 封装、运行记录读写和本地课程阅读器；`knowledge_base/` 存放只读挂载的知识文档；容器运行时的工作区和记录输出到独立可写目录，与评分逻辑隔离。

## 制作与验证流程

每课先对照大纲与固定版本的上游源码确定核心问题，再实现最小脚本与评测检查，结合代码事实编写并润色教材。随后在 Docker 环境下执行对应场景与自动化测试，分别留存受控样本和真实模型运行的原始输出；发布前同步核对 SVG 与 PNG 图件加载情况以及正文与源码的一致性。
