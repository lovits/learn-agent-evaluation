# 已确认需求与项目计划

## 读者与目标

读者会 Python，了解 RAG / Agent。学习重点是实践与关键源码：能设计评测集、选指标、
定位失败，解释两个版本的变化，并沿 DeepEval / Ragas 源码找到评分依据。

贯穿项目为“知识库问答＋工具调用助理”。课程参考 Learn Claude Code 的递进方式，
按评测问题组织，而不按第三方仓库目录写使用手册。

## 教学验收

1. 能区分 supported / unsupported / contradicted，并解释证据缺失与矛盾的不同。
2. 能手算两套 SDK 的聚合结果，指出版本与参数造成的差异。
3. 能运行 5 个回放，在报告中找到证据 hash、声明、裁决与源码版本。
4. 修改挂载知识库后，能观察搜索变化与旧回放拒绝继续评分。
5. 能解释空声明、错误知识库和答非所问为什么需要其他指标补充。

## 后续课程

全课程是 6 单元 24 课，当前完成 s07；其他课是已设计的路线，尚未实现。
下一阶段依次补齐检索评测、答案正确性与相关性，再进入工具调用、多轮、任务完成和回归。
每课维持同一结构：问题 → 最小机制 → 工作原理 → 源码 → 实验 → 验收。

固定回放用于检验评分契约；真实裁判实验需要显式配置模型接口。教学样本不直接作为生产效果证明。
参见 [24 课详细路线](curriculum.md)、[验证记录](validation.md)与 [教材提示词](../generation/textbook_prompt.md)。
