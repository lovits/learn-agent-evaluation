# 第10课参考答案

1. 首轮只有既有工具与connect_mcp，连接后下一轮多出mcp__docs__search/get_version。模型响应schema与当轮工具快照对应；未发现工具不属于当前可调用列表。
2. 三个不同调用全部出现时，换序或增加相同调用不会改变集合；F1仍1。Ragas strict对换序为0，flexible允许换序但不允许多一个重复项；DeepEval加权LCS可对换序部分得分，对尾随重复可能仍1。
3. DeepEval非精确字典分按并集计权，单个read调用得1/2，三调用平均5/6。Ragas按reference键比较，忽略unused所以该例仍1。完整参数集合把多参调用当作另一项，F1降为2/3。query整数可被str比较掩盖，但当前handler要求字符串并拒绝整数。
4. 本课固定结果分别为自写F1=1、原生Ragas F1=0、Accuracy=1、ArgumentCorrectness=1且0次模型请求。没有要求用工具时，应先判断指标适用性；空参数可判不等于业务已完成。
5. 权限依据HOST_POLICY，描述与annotations不授权；默认确认被批量回调拒绝，handler调用计数不增加。tool参数无法覆盖局部绑定，get_version接收多余字段会返回TypeError。
6. 第一轮评分删掉连接与文档调用，误把完整任务交给裁剪后的样本。Agent实际已经连接并获得文档。只修订语义评分输入与新裁判记录，真实文件、Agent运行和第一轮报告保留。
7. 缺失结果会让正确参数失去依据；未来结果会让早期决定看起来掌握尚未取得的信息。按父model span组装先前messages与当轮工具定义，测试应分别证明保留过去和排除未来。
8. 合法完成路径不唯一。业务合同看产物和执行证据；literal工具参考只检查具体名字、参数与序列，不能用单一路径得分否定所有等价解法。
9. print(48)没有执行所要求的6与8相乘，合同拒绝；total=6*8再print(total)保留计算来源，可通过。本课只支持明确的直线整数乘法，不是任意程序功能证明。
