# e05 参考解释

1. k 改变候选数量上限，不承诺所有片段都相关。每次只回填第一条时，其余候选仍留在运行记录，不能据候选数量声称模型输入增加。保持查询和文档固定，才便于观察这一差别。
2. `hits` 是检索结果，`emitted` 是工具回填内容，`model_inputs` 是成功模型调用收到的消息。扩大每次回填数量可能让更多候选进入输入，也可能带来噪声；仅有更多文本不能证明回答改善。
3. 当前循环保留历史工具消息，没有清除第一次搜索。因此限制作用于每次搜索，历史可以累积多条，重复片段也不会自动去重。
4. 新知识版本应不同；原参考绑定的文档哈希不符，参考字段为空，状态为需要重新审核。实际回答可能错误，不能承担独立参考的职责。旧运行仍保留旧片段和旧版本，不能覆写成新资料。
5. 偏移以 Python 字符串下标为单位。字符、UTF-8 字节和模型 token 的长度不同；换错单位会截出另一段文字，破坏可追踪性。
6. 候选和已回填结果可以记录，但最后一条尚未进入后续成功模型调用，不能算进该次调用的实际上下文。保存成功调用的输入快照，可以分清“准备好送出”和“已经成为输入”。
