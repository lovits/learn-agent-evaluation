# 第4课验收记录

本课新增search_knowledge与挂载文档检索，保留前三课能力。最终真实Agent按需检索两份必要文档，写出认证header、最大字节数、超限状态和来源。独立断网verifier读取真实产物，五项合同全部通过。

最终受控检索实验：三个非空情景实际执行DeepEval三种指标、Ragas collections两种指标，共23次真实裁判请求，无指标运行错误。空结果单列规则得分0与原生skip。排序、漏证据、漏标、模型分句波动分别解释，不把不同单位的分数混为同一指标。

首次Agent入口残留故障注入提示，首次SDK保存器也误用了Relevancy字段，失败记录均保留。修复后分别重跑，SDK两轮46次裁判请求，Agent两轮8次模型请求。教材生成另计。

Docker替换知识库挂载后实际检索到新目录的alternate.md、2097152，无需重建镜像。知识库写入被EROFS拒绝，Agent容器没有独立验收标准和宿主机登录凭据。

这是开发教学实验，不测通用检索能力、吞吐、最终回答Faithfulness或严格盲测防作弊。原生裁判输出来自模型，声明切分与相关性判断可能变化。代码检查通过，本地与Docker断网环境各51项测试通过；新测试覆盖排序、去重、空标注、挂载更换、路径约束、轨迹、原生verdict结构和提示回归。
