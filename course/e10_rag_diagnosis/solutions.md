# e10 参考解释

[练习](exercises.md) · [教材](README.zh.md)

1. 资料缺失先对照 documents；模拟检索遗漏需要 native_hits 与 retrieved；组装遗漏需要 retrieved 与实际 contexts。仅看最终上下文不能分清发生位置。
2. 不能。哈希只识别内容变化，需要审核是否影响参考与证据标注；不能自动把任意变化叫错误旧版本。本课 stale_source 是已知改变命令的教学构造。
3. 默认忠实度可能很高，因为回答沿用了给定资料。应先审当前参考与资料版本关系，再更新资料或参考；更忠实地复述错误规范解决不了版本问题。
4. 看资料是否都被抽入 truths、抽取是否保留来源，裁判是否按题目优先级判断。对全部互相矛盾的资料一概要求一致，可能与正确使用当前规范的行为不符。
5. 相关与无关方向各有一个计数，原为 1/3；追加正确声明后均为 1/4。错误支持数量未变，分母变大。无关方向排除了同时被相关资料支持的声明。
6. 不能推广到其他噪声、位置或任务。None 只说明当前来源、版本和传递检查没有发现缺口，不证明生成正确，也不排除混杂证据、细粒度遗漏或裁判问题。
