# 第2课验收记录

本课验收针对具名工具、权限分支、执行轨迹及框架样本转换。实测平台为macOS上的Docker Desktop，容器linux/arm64。

五条开发任务真实运行，全部满足独立任务合同。共16次模型请求、14次工具请求，其中2次权限拒绝、1次参数无效、11次进入执行。固定报告保留模型响应、执行结果、hook、SDK样本和独立判定。

- 正常文件任务：五种工具完成查找、读取、单次替换、运行和写结果，输出48。
- 权限任务：目录外读取、需要批准的删除均被拒绝，文件未改动。
- 缺参任务：故意省略path，执行前返回invalid_arguments。
- 工具错误：不存在文件和错误脚本分别留下error与退出码1，原脚本未修改。
- 结果关联：同轮重复工具保留不同call_id，最终文件按原顺序写入。

独立验收器在network_mode=none的容器运行，练习目录和标准只读；Agent镜像不含evaluation_private、Codex凭据。知识库只读挂载，本课没有检索。

本地32项测试通过，Docker断网环境32项测试通过，代码检查通过。测试覆盖真实文件工具、权限批准/拒绝、目录外符号链接、缺参、错误、错位轨迹、缺hook、假报完成、SDK往返和阅读链接。
