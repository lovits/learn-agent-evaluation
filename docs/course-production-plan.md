# 课程组织

课程以[16课大纲](curriculum.md)为内容索引，以[写作方式](teaching-method.md)为正文标准。每课围绕一个核心问题，把 Agent 代码与评测代码放在同一条可追踪的数据流中。

知识库模块使用 TinyRAG，其余 Agent 机制与课程顺序保持递进。DeepEval、Ragas 的方法按问题接入，源码导读负责解释同名指标之间的实际差异。

PocketFlow 读取课程索引和逐课材料，按已确定的学习顺序组织章节。正文的技术解释以可运行源码为依据，编排不新增模型运行成绩。

发布内容由课程首页、各课教材与源码导读、综合项目组成。Docker 和历史记录作为运行基础与研究材料保留。
