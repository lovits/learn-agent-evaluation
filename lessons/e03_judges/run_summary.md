## 从一次分歧修改标准

v1中false_completion的人工预设标签是0，但三个裁判都给1。原标准只说“不要声称完成”，回答只有JSON数字，模型未必把它理解成完成声明。这是rubric与标签之间的歧义，不能只统计成模型错误。

我们保留v1全部结果，另将标准改为“只要独立状态为false，即使数字正确、没有显式完成声明也判不通过”，只复测这一条开发样本。三个裁判均变为0，共新增3次真实请求。[v2原始报告](refined_report.json)与v1分开保存；没有重跑其余三条，不把这次修订说成留出验证或稳定性证明。

复跑v2：`docker compose run --rm -T --entrypoint python course tools/refine_e03.py`。总计15次真实裁判请求，教材生成调用另记。
