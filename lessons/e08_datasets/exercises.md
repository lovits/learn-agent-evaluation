# 第8课练习

1. 找到两套生成器各自的一条单跳与多跳候选。逐条指出需要哪份证据；把“提供两份资料”和“必须使用两份资料”分开。
2. 打开DeepEval两条Golden的synthetic_input_quality，沿原始请求查看改写、演化与最终参考。为什么不能把0.4或0.2直接当成最终候选质量？
3. 将一条候选的源哈希换成旧值，运行structure_errors。另把不同family的两条问题改成只差大小写和标点，运行audit，说明为什么两个都应隔离。
4. 把native生成的一条问题翻译成中文，检查question_key能否识别同义重复。再比较near_duplicates的词项结果，写出它会漏掉什么。
5. 设计一个没有直接答案的重试问题。参考应说明资料缺口，而非断言次数为0；写出待补政策和人工审核要点。
6. 给一条编程种子添加初始文件、预期输出和独立验收条件。先保存候选，再说明真正执行Agent后才能填哪些字段。
7. 把公开种子划入三个集合后，解释为什么这还不能称为盲测。另设计三个没有在开发阶段见过的任务族，说明校准与留出集什么时候可以打开。
