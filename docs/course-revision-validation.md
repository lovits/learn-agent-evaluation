# 整套课程重写阶段验收

本记录按阶段追加实际完成证据。当前验证第2至7课的正文重写；第1课的改写另有独立记录。第8至16课与综合项目仍待制作。

## 第2、3课正文

两课均采用问题、解决方案、工作原理、相对上一课的变更、试一下、接下来六部分；每课有六个短代码步骤和三个观察题。完整源码、练习、答案、框架分析与历史实验保留在附页。

技术审校纠正了生成稿中的示意变量、glob返回路径类型、F1零分母分支及遗漏的评分标准语句，最终片段按当前实现解释。随后humanizer通读两课各12节，润色时校验代码块、行内代码、命令和链接保持不变。

原Agent、评分代码、样本与固定JSON报告用逐文件SHA-256和改写前基线比较，保持一致。原生成稿、brief与凭证保存在generation/archive；本次PocketFlow各实际调用写作模型一次。本次没有重新执行Agent或模型裁判，不把历史成绩写成新测量。

本地、Docker、阅读页和飞书同步的实际结果见[机器记录](https://github.com/lovits/learn-agent-evaluation/blob/main/docs/course-revision-validation.json)。

本地与Docker断网均78项测试通过，自有代码Ruff检查通过。保留1条既有DeepEval DAG接口弃用警告。实际HTTP检查第2、3课均返回200，六部分标题准确，代码块分别17、13个。飞书第2、3课均回读版本7，主文代码块逐个与发布稿比较一致，源码/练习/答案等未选中附页保留；结果附页增加历史说明。

四课均已重新运行PocketFlow，每课本轮写作调用1次，并经源码与历史报告核对。正文各有六部分、六步短代码与三个观察题，humanizer各审校12节，未审校0。第4课补齐排序代码与完整产物检查条件，第5课区分重新调用裁判与回放，第6课加入实际参考澄清片段，第7课修正产物结构片段并将两个常驻入口分终端启动。
