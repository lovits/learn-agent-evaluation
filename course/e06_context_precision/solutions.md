# e06 参考解释

[练习](exercises.md) · [教材](README.zh.md)

1. 三种排列都包含 `1` 条相关项和 `3` 条总候选，因此普通精度均为 `1/3`。但在唯一相关位置上的 `P@i` 依次为 `P@2 = 1/2`（原序 `[0,1,0]`）、`P@1 = 1`（首位 `[1,0,0]`）和 `P@3 = 1/3`（末位 `[0,0,1]`）；由于列表内相关数为 `1`，三者的 `list_ap` 也依次等于 `1/2`、`1` 和 `1/3`。
2. 普通精度从 `1/3` 降到 `1/4`，而 `list_ap` 仍为 `1`。新增的尾部噪声排在所有相关项之后，既不改变前面相关位置上的 `P@i`，也不会进入分子或分母的求和。因此高 `list_ap` 只能说明相关项靠前，无法代表列表中没有尾部噪声。
3. 对于 `[1,0,1]`，`rr` 为 `1`，`list_ap` 为 `(1 + 2/3) / 2 = 5/6`。`rr` 只关心第一个相关项出现的位置，拿到第 `1` 位的倒数后就不再受后面片段顺序影响；`list_ap` 则会把列表里每一个相关位置的 `P@i` 都纳入平均。MRR 是多个独立查询各自 `rr` 的平均值，针对单个查询只能报告 `rr`。
4. 片段级 `ContextualPrecisionMetric` 评估该片段整体是否有助于得出参考答案，只要里头包含所需依据就能得到 `yes`；而陈述级 `ContextualRelevancyMetric` 会把片段拆解成多条陈述并逐条判别，其余 `3` 条无关背景都会拉大分母。两项指标的判断单位与分母定义不同，对比前必须先看清楚计数单位。
5. `list_ap` 的分母只统计当前已经返回的列表中有多少相关片段，并没有检查知识库里原本存在、却没被检索出来的其余证据。衡量“该找的证据有没有漏掉”需要从参考事实清单出发计算覆盖率与召回率，这正是下一课的主题。
6. 模型少返回一条裁决属于格式或对齐缺失，并不能确定没返回的那一段究竟是相关还是无关。此时应当保留原始返回、标记为 `status="error"` 并置空分数以便排查。另外，裁决条数与片段数相等只是最基础的对齐检查，即使数量一致，仍需对照 `verdicts` 里的理由确认没有张冠李戴。
