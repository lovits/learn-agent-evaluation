## 构造协议控制

同一正式镜像在Docker断网执行实际后台进程、超时、非零退出、单次通知、旧收据与新源码不同，以及受控cron提前/重复/失败恢复/重启交付。9项条件全部观察到，模型调用0次。请求由讲师构造，不是模型自主故障率。

原生Ragas add_retry实际先抛构造TimeoutError、第二次返回，max_retries=2在此限制包含首次的总尝试2次。另一个真实函数在timeout字段为1秒时执行超过1秒仍返回，展示该包装器本身不实施期限。原生CostCallbackHandler用构造的1500输入、150输出token及讲师单价算出0.0036演示单位；不是市场现价或Codex订阅账单。

单元协议另外覆盖持久化失败回滚、ack写盘失败恢复队列、损坏记录可见错误和实际模型输入的通知/定时文本。状态fixture的“模型”是明确的注入回调，未调用供应商，不与正式54次应用响应混计。
