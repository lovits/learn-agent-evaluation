# 课程的讲解方式

每课都从具体任务或典型失败切入，先让读者遇到问题，再给出解决它的最小机制。正文节奏跟随 Learn Claude Code 的实战讲法，围绕当前机制安排小节结构。

行文沿着数据流动展开：任务从哪里进来，模型每次真正看到什么输入，关键函数改变了哪些状态，评分器依据什么证据得出结论。完整实现留在源码文件里，正文只摘录理解核心逻辑所需的代码片段。

每课聚焦一个评测知识点。知识库检索采用 Datawhale TinyRAG，编程 Agent 沿用 Learn Claude Code 的循环架构，所有指标与样本统一接入 DeepEval。各指标课直接复用前面搭好的 Agent 内核，不为讲单一指标额外堆砌功能。

## 教材与源码导读

主教材从具体故障出发，用短代码配合手算或受控示例讲清原理，最后留下可动手验证的问题。手算数字只用来解释算式，在文中标明对应样本或控制条件；制作过程、安装步骤与运行成绩清单集中存放在各课 `assessment.md` 与 `assessment.json` 中，保持正文主线专注。

源码导读深入到具体函数、字段约束、结构化裁决与聚合公式，说明 DeepEval 指标的极性、分母构成以及空值或异常边界，并将代码链接固定到上游提交哈希。涉及代码交付的任务会单独解释独立行为检查的依据与覆盖边界。

## 语言与配图

先讲清楚为什么需要这个机制，再展示对应的关键代码。段与段之间用具体变量名和输入输出衔接，减少术语堆砌与重复总结。流程图只在文字难以直观呈现多阶段数据流或门禁分支时使用，并保持节点文字简练。

## 源码与运行记录

前 15 课各自只接入已经讲过的共享模块，完整的端到端组合放在第 16 课结课项目。容器环境与知识库只读挂载由 `compose.yaml` 负责管理，原始运行日志按编号保存在 `runs/` 与各课记录文件中，方便读者随时回溯对照。
