# 第11课：任务完成，先检查，再允许结束

严格遵循references/textbook-writing-standard.md，以已读Learn Claude Code s01/s17的带读方式：一个具体困难，最小增量，沿真实数据流拆代码。主文2000至3500中文字，代码另算；仅六个二级标题“问题、解决方案、工作原理、相对上一课的变更、试一下、接下来”。工作原理6个加粗步骤，每步现有源码局部5至15行，注明省略；完整模块用相对链接，不整段贴Agent。不要发明函数、字段和实验结果；完整机制细节放source_walkthrough附页，知识点不丢。无图占位、无Mermaid、本课简单状态用表即可。

从shipping_fee运费修复进入：初始1001g返回600，合同应为800；知识库可挂载。精确int重量1..5000（拒bool），精确bool加急，类型先TypeError，范围ValueError，起步1000g600分，每开始额外1000g200分，加急300分。保留测试。模型口头结束时，文件未必正确。

解决方案：保留e04真实Agent循环、e02文件工具/权限和e10动态工具池/宿主模型桥，在run_case外层加目标公开审查；独立Docker验收器稍后检查其他输入。本课不是换成问答机器人，也不引入计划记忆或后台。GoalState仅对公开例子与测试保留给ready_for_external_verification，不宣称完整成功。最多3审查轮，每段12模型步；blocked把实际反馈加到history后续轮；review_error/limit保留条件；显式retain_public_tests与delete_all_tests冲突返回impossible且0次模型。该冲突分支是事先已声明的逻辑约束，不是自由文本理解。

工作原理六步：
1. code.py run_case保留ToolPool和既有agent_loop。模型只给动作JSON，工具在Docker执行。先生成停止候选finished，和完整任务完成分开。
2. verify.py probe读shipping.py和test_shipping.py哈希，通过runner子进程实际调用函数。5至10行真实片段；结果对比返回值+精确类型或异常类，保护测试文件。公开3例，独立保留20例，先冻结Agent产物再验收；不回流保留题。输出源码哈希/diff线索。
3. GoalState.review +续轮接入短片段。公开失败blocked，history保留实际模型/工具消息，反馈不通过时下一段同一已发现工具池继续。不完整照搬s17，只取停止位置审查；上游是独立模型读对话，本课公开规则审查，可复核。显式合同冲突和错误都不标完成。
4. 规则业务指标metrics.py ExternalCompletionMetric（原生DeepEval BaseMetric）measure/a_measure，RagasExternalCompletion ascore/score。metadata传可信外部checks，结构严格验证；全True=1，有False=0，不支持/异常/空检查unscored分null。本轮实际验证同步异步一致。规则不请求LLM。
5. 原生TaskCompletion与AgentGoalAccuracy两阶段抽取和判断。给实际短调用，不抄完整eval。DeepEval官方推荐完整trace，本课固定源码直接measure兼容input/actual_output分支；本课序列化对话和外部检查，不伪装原生SDK trace。TaskAndOutcome→TaskCompletionVerdict float，RagasWorkflowOutput(user_goal,end_state)→CompareOutcomeOutput字符串0/1；WithRef用reference，WithoutRef用推断goal。Ragas MetricResult.reason本轮None，但实际解释在捕获的第二阶段schema结果中。详细prompt/async/校验留源码导读。
6. 用真实误判讲组合：early_claim_only只有业务请求和实际“Completed”回答，DeepEval实际给1，而且抽取outcome补出了未证实的类型修复、边界和独立检查通过；Ragas两种均0。early_with_public_check加入同一时刻真实公开结果，DeepEval0.2，Ragas均0；文件和Agent没有重跑，属于评分输入差别。公开3例均过的讲师partial公式，完整检查失败，DeepEval0.35，Ragas0。组合min(rule,judge)，rule0不能被judge1抬高；规则缺失保持unscored。主文一个短算例即可，更多表附页。

本轮真实实验：2次模型Agent运行，12个模型响应15个工具请求；正常1轮，明确故障注入先假报完成0工具再修复2轮，不能称自然故障率。两次均独立23输入通过并保留测试。6个讲师构造状态独立运行验收：只改说明、删测试、假报成功、只修公开例子、重复多加费用、import不适用；最后者unscored，不是0。初次代码未含独立冲突预检，补充Docker单独执行冲突分支，原两次Agent与原裁判记录不伪造重跑。4种评分投影实际24裁判请求12指标结果0错误；未知模型ID/费用不填。
