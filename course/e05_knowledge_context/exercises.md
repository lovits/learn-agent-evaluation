# e05 练习

[教材](README.zh.md) · [实现](code.py)

1. 固定同一条查询，比较 `k=1` 与 `k=3`。哪些候选增加了？当 `context_limit` 保持为 1 时，模型实际收到的输入会自动增加吗？
2. 保持 `k=3`，把 `context_limit` 从 1 改为 2。分别查看 `hits`、`emitted` 和最后一次 `model_inputs`，说明这三个字段各自记录了什么。
3. 让 Agent 连续搜索两次。为什么每次只回填 1 条，最终样本里的 `retrieval_context` 却可能出现 2 条？
4. 在另一个只读挂载目录里修改发布检查命令。新运行的知识版本号和旧参考字段分别会发生什么变化？为什么不能拿 Agent 的实际回答去补填参考？
5. 任选一个文档片段，验证 `text == 文档[start:end]`。如果下游代码把 `start` 和 `end` 误当成 token 偏移来切片，会出现什么问题？
6. 假设循环在最后一次搜索完成后刚好达到步数上限，没有触发下一次模型调用。这次搜索的结果应该记在候选记录里，还是记在模型的实际上下文里？
