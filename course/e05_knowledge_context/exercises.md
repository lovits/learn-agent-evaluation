# e05 练习

[教材](README.zh.md) · [实现](code.py)

1. 固定同一查询，比较 k=1 与 k=3。哪些候选增加了？每次回填数量仍为 1 时，模型输入会自动增加吗？
2. 保持 k=3，将 `context_limit` 从 1 改为 2。分别检查 `hits`、`emitted` 和最后一次 `model_inputs`，说明三个位置的含义。
3. 让 Agent 连续搜索两次。为什么每次回填 1 条，最终 `retrieval_context` 可能有 2 条？
4. 在另一个挂载目录中修改发布命令。新运行的知识版本和旧参考各发生什么变化？为什么不能用实际回答补上参考？
5. 找一个长文档片段，对照 `text == 文档[start:end]`。这些偏移若误按 token 使用，会怎样？
6. 让循环达到步数上限，最后一次搜索结果还没进入下一次模型调用。它应出现在候选记录里，还是实际模型上下文里？
