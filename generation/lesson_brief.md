# 第1课任务：定义成功

按新16课大纲制作第1课。不是只改文案：教材必须对应当前 code.py、eval.py、eval_course/runtime.py 与公开任务。

核心问题：模型停下了，任务就完成了吗？任务是创建只含 print("Hello, World!") 的 hello.py 并运行。先让读者看到一句“已经完成”不能提供文件与执行证据，再引入最小循环和独立评分。

参考 Learn Claude Code s01 中文课文的讲法：问题、解决方案、工作原理、变更内容、试一试。按知识点组织段落，不固定步骤数。关键片段来自真实文件，标明片段用途；省略传输和日志的片段不能冒充完整程序。

本课只介绍模型、Harness、Bash、消息回填和任务规则。code.py 的 agent_loop 是教学主干；runtime.py 收集原有模型传输、进程执行与目录准备，供按需阅读。不要提前加入检索、具名工具、完整 trace 平台或 SDK 裁判。

空 tool_calls 对应 finished；这只是循环停止。工具非零可以回填模型；step_limit 和 model_error 均不是完成。模型接口只提供动作，Bash 在 Docker 中执行。Codex 登录留在宿主，不将 Codex 自身工具当作被测 Agent。

独立评分从真实 events 和文件取证。hello 任务要求出现成功输出，文件 AST 符合单条 print，并且循环正常结束。通过比例帮助定位，只有全部条件满足才 passed。普通 stderr 包含失败不等于任务失败：command_error 的目标就是观察原错误。AST 规则不证明任意程序等价，也不证明模型解释正确。

DeepEval 与 Ragas 本课只作为任务、运行、指标分工的依据，不声称本课调用了原生 SDK 指标。源码导读给固定提交，实际 SDK 样本从第2课开始。

下一课的问题是：如何把一次运行变成可追溯、能送给框架的样本？具名工具和权限围绕这个问题加入。

正文不放实测成绩、制作进度、验收报告、阅读服务启动教程。试一试可给执行单任务和评分的入口，让 AI 按项目配置准备环境。运行证据另外保存，真实模型与构造反例明确区分。
