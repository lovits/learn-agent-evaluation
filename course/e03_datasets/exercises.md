# e03 练习

1. 给 `auth-paraphrase` 换一个 `intent`，再整理数据。为什么它会留下来？这说明去重依赖哪个判断？
2. 将 `size-limit` 放进开发集，保留 `size-overflow` 在留出集。调用 `check_dataset`，找到泄漏的题族。
3. 把资料中的大小上限改成另一数值。只更新候选的哈希、不核对参考答案，足以恢复数据可信度吗？
4. 让模型生成候选后，检查它们的审核状态。为什么存在问题、参考和引文还不够？
5. 选出一条缺证据题，说明回答范围以及合理参考。它与没有来源、无法判断对错的坏题有什么区别？
6. 运行一条已批准任务。找出任务、参考、实际回答和工具输出，说明为什么目前还没有答案质量分数。
